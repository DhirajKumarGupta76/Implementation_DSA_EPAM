## ⚙️ How to Run the Programs

You can clone this repository and execute individual C++ programs on your local machine.

**1. Clone the repository**

```bash
git clone https://github.com/DhirajKumarGupta76/Implementation_DSA_EPAM
```

**2. Navigate to the repository**

```bash
cd Implementation_DSA_EPAM
```

**3. Compile any C++ program**

```bash
g++ LINKEDLIST/SinglyLinkedList/Cycle.cpp -o Cycle
```

**4. Execute the program**

```bash
./Cycle
```

For Windows:

```bash
Cycle.exe
```
